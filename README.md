# Kelechi Aliegbere – Portfolio

Personal portfolio showcasing my projects, skills and contact details.

🔗 **Live site:** https://portfolio-nine-theta-10.vercel.app/

## Built With
React, Tailwind CSS, Node.js, Express js, Postgres(Neon DB), Render

## Sections
- About me
- Projects (File Scanner, KelsBooking, Booking System, Smart Library System)
- Skills
- Contact

## Run Locally
1. `git clone https://github.com/Kelechiemmanuel/Portfolio.git`
2. `npm install`
3. `npm run dev`
